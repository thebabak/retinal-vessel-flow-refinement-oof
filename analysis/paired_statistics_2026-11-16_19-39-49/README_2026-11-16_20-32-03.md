# Additional exploratory paired analysis

This report analyzes nine unchanged CSV sources after the original outcomes had already been inspected. It adds explicit per-image Dice values/differences and paired diagnostics without changing the original models, predictions or saved bootstrap intervals. Five refiner fits share one frozen baseline and one OOF-map source per dataset. These are not five independent baseline fits or a prospective confirmatory experiment.

Two-sided t and exact signed-rank tests have separate Holm families: nine recipe-specific comparisons and nine baseline-secondary comparisons, separately at the refiner-seed and patient/image levels. With five nonzero seed differences the minimum attainable two-sided exact signed-rank p-value is 0.0625. The unadjusted t intervals identify their unit and differ from the original cohort-bootstrap intervals. See the interpretation constraints for assumptions and scope.

All copied CSV, script, test, table and report files retain their original bytes. The public configuration removes private machine-specific source paths and records the SHA256 of the original plan; it is explicitly a derivative, not the original registered file. Source CSV hashes and analysis definitions are unchanged.

To rerun the CSV-only analysis in a fresh output directory (NumPy and SciPy required):

```bash
python analysis/paired_statistics_2026-11-16_19-39-49/analyze_paired_records_2026-11-16_19-39-49.py --config analysis/paired_statistics_2026-11-16_19-39-49/public_analysis_plan_2026-11-16_20-32-03.json --output runs/paired_statistics_NEW_LOCAL_TIMESTAMP
```

The command calculates statistics but loads no image, prediction tensor or model. It refuses to overwrite an existing analysis. Synthetic implementation checks can be run with:

```bash
python analysis/paired_statistics_2026-11-16_19-39-49/test_paired_statistics_2026-11-16_19-39-49.py
```
